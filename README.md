# نساجی اسپرت — سایت جدید

سایت خبری nassajisport.com با Next.js، فارسی و راست‌چین، همراه با پنل مدیریت کامل.

## اجرا

```bash
npm install
cp .env.example .env      # ADMIN_PASSWORD را عوض کنید
npm run build && npm start
npm test
```

- سایت: `http://localhost:3000`
- پنل مدیریت: `http://localhost:3000/admin/`

## پنل مدیریت

| بخش | کار |
|---|---|
| خبرها و برگه‌ها | نوشتن، ویرایش، پیش‌نویس، انتشار زمان‌بندی‌شده، خبر ویژه، تصویر شاخص، سئو |
| دسته‌ها | افزودن، تغییر نام و نامک، حذف |
| رسانه | بارگذاری عکس و ویدیو، کپی آدرس، حذف |
| جدول و بازی‌ها | نتیجه‌ی زنده (دقیقه و گل)، برنامه‌ی بازی‌ها، جدول لیگ با محاسبه‌ی خودکار امتیاز |
| بازیکنان و کادر | پروفایل بازیکن با عکس و آمار، کادر فنی |
| ترکیب بازی | ترکیب هر دو تیم، آرایش، سرمربی و ذخیره‌ها؛ با پیش‌نمایش زمین |
| ظاهر و تم رنگی | ۸ تم آماده، رنگ دلخواه، حالت روشن/تیره/خودکار |
| تنظیمات | نام سایت، لینک خرید بلیت، شبکه‌های اجتماعی |
| مدیران | افزودن و حذف مدیر، تغییر رمز |
| درون‌ریزی وردپرس | بارگذاری فایل XML خروجی وردپرس |

تاریخ‌ها در پنل شمسی و به وقت تهران وارد می‌شوند.

### اولین ورود

تا وقتی هیچ مدیری تعریف نشده، ورود با `ADMIN_USERNAME` و `ADMIN_PASSWORD` از تنظیمات سرور انجام می‌شود و همان کاربر ساخته می‌شود.
بعد از آن رمزها در پنل مدیریت می‌شوند.

## داده‌ها

همه‌ی داده‌ها در پوشه‌ی `data/` (یا `DATA_DIR`) به‌صورت فایل JSON ذخیره می‌شود، به همراه عکس‌ها در `data/uploads/`.
این پوشه پایگاه داده‌ی سایت است: **مرتب از آن نسخه‌ی پشتیبان بگیرید** و آن را در git نگذارید.

دفعه‌ی اول، این پوشه از محتوای `content/` ساخته می‌شود (محتوای نمونه، یا خروجی `npm run import:wp`).

## میزبانی

سایت به یک سرور با Node.js 22 نیاز دارد که بتواند در پوشه‌ی `data/` بنویسد (مثلاً یک VPS).
میزبانی‌های بدون فایل‌سیستم قابل نوشتن (مثل Vercel) برای پنل مدیریت مناسب نیستند.
پشت HTTPS اجرا کنید؛ کوکی ورود مدیر فقط روی HTTPS فرستاده می‌شود.

## انتقال از وردپرس

1. در پیشخوان وردپرس: **ابزارها ← برون‌بری ← همه‌ی محتوا**.
2. در پنل مدیریت، بخش «درون‌ریزی وردپرس»، فایل XML را بارگذاری کنید.
3. پوشه‌ی `wp-content/uploads` سایت قدیم را در `data/uploads/` کپی کنید.

خبرها با همان آدرس‌های قبلی منتشر می‌شوند. خبرهایی که در پنل نوشته شده‌اند با درون‌ریزی دوباره حذف نمی‌شوند.

## ساختار

- `app/(site)/` — صفحه‌های عمومی سایت
- `app/admin/` — پنل مدیریت
- `app/uploads/` — سرو فایل‌های بارگذاری‌شده
- `lib/` — داده‌ها، احراز هویت، تم‌ها، تاریخ شمسی
- `scripts/import-wordpress.mjs` — تبدیل خروجی وردپرس (در پنل و خط فرمان)
- `content/` — محتوای اولیه
